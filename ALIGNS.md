# Quiet Terminal project alignment

## Direction

Quiet Terminal is an Even Realities G2 companion application. It combines private writing, document management, an Even Terminal client, X timeline reading, and localized RSS news. The phone shows a typewriter scene while the glasses show the active text or information.

## Priorities

1. Reliable input, readable glasses output, and predictable navigation.
2. Protect user documents and credentials; describe storage and network limits accurately.
3. Maintain the approved typewriter design and a coherent glasses interface.
4. Keep the app understandable and maintainable, with strict TypeScript checks.
5. Test with the simulator and real iPhone, glasses, and ring where possible; report their results separately.

## Working agreements

Use the user's preferred language in conversation. Keep application interface text in English. Use the requested main branch. Existing Even Terminal server behavior and documented Even Hub network permissions define integration boundaries; do not imply unverified wildcard access or secure storage. Seek explicit approval for external prose drafts as requested by the user.
