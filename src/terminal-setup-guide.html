1. Connect Tailscale

Install Tailscale on the phone and computer. Sign in to the same network.

2. Start Even Terminal

Install Even Terminal and run these commands on the computer:

npm install -g @evenrealities/even-terminal
even-terminal --provider codex --tailscale --allow-cors

Keep the server running. Use its connection token.

3. Set up HTTPS

Enable MagicDNS and HTTPS certificates in Tailscale DNS settings. Then run:

tailscale serve --bg http://127.0.0.1:3456

Enter the printed HTTPS address and connection token in the previous screen. This build allows only permitted server addresses. Tailscale Serve guide
