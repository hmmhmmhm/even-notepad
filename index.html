Connect Even Terminal

The connection token is saved in this device’s app storage.

Select a computer.

1. Open your app’s keys

Open X Developer Console, select Apps, choose your app, then open Keys & Tokens.

2. Copy the Client ID

In the OAuth 2.0 section, copy Client ID. Paste it into the Client ID field in Quiet Terminal. Do not copy Client Secret.

3. Generate your user tokens

In the same OAuth 2.0 section, find Access Token and select Generate. Complete any authorization steps shown by X. Copy the resulting access token and refresh token into the matching fields in Quiet Terminal, then choose Save connection.

Use the OAuth 2.0 user tokens, not the app-only Bearer Token at the top or the OAuth 1.0a Access Token. Keep tokens private.

If token generation is unavailable, configure your X app for user authentication. A public client and the tweet.read, users.read and offline.access permissions are needed for this setup. Timeline access also depends on your X API plan.
